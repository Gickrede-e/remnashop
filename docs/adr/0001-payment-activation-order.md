# Последовательная активация оплат одного пользователя

Подтверждённые платежи одного пользователя активируются последовательно: следующая покупка ждёт завершения предыдущей, включая повторные попытки после сбоя. Расчёт сохраняется только для первой ожидающей активации, чтобы два платежа не продлевали подписку от одной и той же исходной даты. Независимую активацию более поздней покупки отклонили: сохранённый расчёт предыдущей мог бы затереть её начисление; принимаем задержку последующих покупок при сбое первой.
