# Подписки RemnaShop

Пользователь оплачивает тариф, чтобы получить или продлить доступ к сервису.

## Термины

**Платёж**:
Одна оплата пользователем выбранного тарифа. Два разных платежа дают право на два отдельных начисления.

**Активация подписки**:
Предоставление или продление доступа по подтверждённому платежу с учётом положенных бонусов. Повторная попытка завершает ту же активацию и не даёт права на дополнительное начисление.
_Избегать_: активация платежа.

**Очередь активаций**:
Подтверждённые платежи одного пользователя, ожидающие предоставления доступа. Следующая активация ждёт завершения предыдущей, в том числе после сбоя; платежи разных пользователей независимы.

**Учётная запись Remnawave**:
Запись в панели Remnawave, связанная с пользователем магазина и предоставляющая ему доступ к сервису. Содержит срок, лимиты и параметры доступа.

**Код подтверждения**:
Одноразовый код из письма для подтверждения адреса при регистрации или восстановления доступа.

**Повторная отправка кода**:
Запрошенное пользователем новое письмо с кодом на тот же адрес. Подготовка проверки посетителя сама по себе не отправляет письмо.
